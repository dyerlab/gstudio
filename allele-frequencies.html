This chapter covers estimating allele and genotype frequencies, testing for Hardy-Weinberg Equilibrium, and rarefaction analysis.

4.4 Hardy-Weinberg Equilibrium

The hwe.test() function tests for HWE using a chi-square approximation. A single locus gives a standard test, printed like chisq.test():

arapat |>
  filter(Species == "Mainland") |>
  pull(LTRS) |>
  hwe.test()
Warning in .hwe_chisq(x[[loci]], label = loci, suppress_warnings =
suppress_warnings): Under 50 samples for pull(filter(arapat, Species ==
"Mainland"), LTRS) this may not be a good approximation.
Warning in .hwe_chisq(x[[loci]], label = loci, suppress_warnings =
suppress_warnings): Fewer than 5 genotypes expected at pull(filter(arapat,
Species == "Mainland"), LTRS) consider collapsing alleles.

    Chi-square test for Hardy-Weinberg equilibrium with continuity

4.4.1 Interpreting Results

Departures from HWE can arise from:

  • Non-random mating (inbreeding, assortative mating)
  • Population substructure (Wahlund effect)
  • Selection at or near the marker locus
  • Small population size (genetic drift)

4.5 Rarefaction

Diversity statistics such as allelic richness grow with sample size, so strata sampled unequally cannot be compared directly. rarefaction.test() rarefies each locus to the smallest number of genotyped individuals in any stratum: every larger stratum is resampled nperm times without replacement at that size, and the table gives the observed value, the mean across resamples (estimate) and a percentile interval (conf.low, conf.high) for each stratum, locus and mode. With several loci, a Multilocus row per stratum combines each resample across loci. It is NA for a stratum missing any of the loci, so strata are compared over the same loci; na.rm = TRUE combines the loci that are available instead.

set.seed(1)
rare <- arapat |>
  rarefaction.test(stratum = "Species", mode = c("A", "Ae"), nperm = 199)
rare |>
  filter(Locus == "Multilocus")

    Rarefaction without replacement (199 resamples)

data:  arapat by Species
size:  smallest stratum at each locus

    Stratum      Locus Mode  N size observed estimate conf.low conf.high
1      Cape Multilocus    A NA   NA    2.625    2.318    2.125     2.625
2      Cape Multilocus   Ae NA   NA    1.391    1.387    1.310     1.460
3  Mainland Multilocus    A NA   NA    3.625    3.625    3.625     3.625
4  Mainland Multilocus   Ae NA   NA    1.979    1.979    1.979     1.979
5 Peninsula Multilocus    A NA   NA    4.875    3.519    3.119     3.881
6 Peninsula Multilocus   Ae NA   NA    2.208    2.156    2.012     2.330
rare |>
  filter(Mode == "A", Locus != "Multilocus") |>
  ggplot(aes(Locus, estimate, colour = Stratum)) +
  geom_pointrange(aes(ymin = conf.low, ymax = conf.high),
                  position = position_dodge(width = 0.5)) +
  labs(y = "Rarefied allelic richness") +
  theme_minimal()

Set size = to rarefy to a fixed number of individuals instead; strata with fewer genotypes at a locus are NA. The resampled values for each row are kept in the list-column values, which printing hides.

4.6 Optimal Sampling

The optimal_sampling() function estimates how many individuals are needed to capture a given proportion of allelic diversity:

arapat |>
  pull(LTRS) |>
  optimal_sampling(nrep = 99)

## Rarefaction

Diversity statistics such as allelic richness grow with sample size, so strata sampled unequally cannot be compared directly.  `rarefaction.test()` rarefies each locus to the smallest number of genotyped individuals in any stratum: every larger stratum is resampled `nperm` times without replacement at that size, and the table gives the observed value, the mean across resamples (`estimate`) and a percentile interval (`conf.low`, `conf.high`) for each stratum, locus and mode.  With several loci, a `Multilocus` row per stratum combines each resample across loci.  It is `NA` for a stratum missing any of the loci, so strata are compared over the same loci; `na.rm = TRUE` combines the loci that are available instead.

```{r}
set.seed(1)
rare <- arapat |>
  rarefaction.test(stratum = "Species", mode = c("A", "Ae"), nperm = 199)
rare |>
  filter(Locus == "Multilocus")
```

```{r}
rare |>
  filter(Mode == "A", Locus != "Multilocus") |>
```
