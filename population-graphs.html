8  Population Graphs

Population Graphs are a graph-theoretic approach to understanding among-population genetic connectivity (Dyer & Nason 2004). Rather than assuming a specific model of gene flow (e.g., island or stepping-stone), population graphs estimate the conditional genetic covariance structure among populations, retaining only statistically significant edges.

library( gstudio )
library( dplyr )
library( igraph )
library( ggplot2 )
data( arapat )

8.1 Constructing a Population Graph

8.1.1 From a Data Frame

The easiest way to create a population graph is with population_graph(), which handles the conversion from genotypes to multivariate data internally:

graph <- arapat |>
  population_graph( stratum = "Species" )

8.5 Congruence Testing

8.5.1 Topology Congruence

Compare the topology of two population graphs. Here we ask whether two independent sets of markers give the beetles the same graph, building one graph from the first four loci and one from the last four:

graph_a <- arapat |>
  select( Population, LTRS, WNT, EN, EF ) |>
  population_graph()

graph_b <- arapat |>
  select( Population, ZMP, AML, ATPS, MP20 ) |>
  population_graph()

graph_a |>
  congruence_topology( graph_b )

8.5.3 Edge Stability

The permute_popgraph() function bootstraps individuals within each stratum, rebuilds the graph nboot times (default 999) and returns a graph whose edge weights are the fraction of bootstrap graphs containing each edge:

boot_graph <- mv |>
  permute_popgraph( groups, nboot = 999 )

8.8 Plotting

plot() draws a Population Graph with ggplot2 and returns a ggplot you can extend with +. Nodes are placed from Longitude/Latitude vertex attributes when present (for example after decorate_graph()), and otherwise with a Kamada-Kawai layout; pass layout = to choose another layout name, a layout function, or a coordinate table. The same layout, node_size, node_labels, node_fill, edges and edge_width options apply to plot() on a gravity field and to animate_popgraphs(). Directed graphs from asymmetric_popgraph() are drawn with arrows. For fully custom figures, use ggraph (see the Visualization article).

lopho |>
  plot()

On a decorated graph, nodes are placed at their coordinates. For context, draw the graph over a map: base = takes any ggplot, here a grey outline of the land from Natural Earth (the rnaturalearth package), and the graph’s layers go on top. The Visualization chapter (Chapter 12) adds sea labels and a north arrow.

countries <- c( "Mexico", "United States of America" )
land      <- rnaturalearth::ne_countries( country = countries,
                                          scale = "medium",
                                          returnclass = "sf" )

baja_map <- ggplot() +
  geom_sf( data = land, fill = "grey92", colour = "grey55" ) +
  coord_sf( xlim = c( -116, -108.5 ), ylim = c( 22.5, 32.5 ) )

lopho_dec |>
  plot( base = baja_map )

Population Graphs are a graph-theoretic approach to understanding among-population genetic connectivity (Dyer & Nason 2004). Rather than assuming a specific model of gene flow (e.g., island or stepping-stone), population graphs estimate the conditional genetic covariance structure among populations, retaining only statistically significant edges.

## Constructing a Population Graph

### From a Data Frame

The easiest way to create a population graph is with `population_graph()`, which handles the conversion from genotypes to multivariate data internally:

```{r}
graph <- arapat |>
```

## Plotting

`plot()` draws a Population Graph with ggplot2 and returns a `ggplot` you can extend with `+`. Nodes are placed from `Longitude`/`Latitude` vertex attributes when present (for example after `decorate_graph()`), and otherwise with a Kamada-Kawai layout; pass `layout =` to choose another layout name, a layout function, or a coordinate table. The same `layout`, `node_size`, `node_labels`, `node_fill`, `edges` and `edge_width` options apply to `plot()` on a gravity field and to `animate_popgraphs()`. Directed graphs from `asymmetric_popgraph()` are drawn with arrows. For fully custom figures, use ggraph (see the Visualization article).

```{r}
lopho |>
  plot()
```

On a decorated graph, nodes are placed at their coordinates.  For context, draw the graph over a map: `base =` takes any ggplot, here a grey outline of the land from Natural Earth (the `rnaturalearth` package), and the graph's layers go on top.  The Visualization chapter (@sec-visualization) adds sea labels and a north arrow.

```{r}
#| message: false
#| fig-width: 6
#| fig-height: 6
countries <- c( "Mexico", "United States of America" )
land      <- rnaturalearth::ne_countries( country = countries,
                                          scale = "medium",
                                          returnclass = "sf" )

baja_map <- ggplot() +
  geom_sf( data = land, fill = "grey92", colour = "grey55" ) +
  coord_sf( xlim = c( -116, -108.5 ), ylim = c( 22.5, 32.5 ) )

lopho_dec |>
  plot( base = baja_map )
```
