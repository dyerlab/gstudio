8  Population Graphs

Population Graphs are a graph-theoretic approach to understanding among-population genetic connectivity (Dyer & Nason 2004). Rather than assuming a specific model of gene flow (e.g., island or stepping-stone), population graphs estimate the conditional genetic covariance structure among populations, retaining only statistically significant edges.

library(dplyr)

8.8 Plotting

plot() draws a Population Graph with ggplot2 and returns a ggplot you can extend with +. Nodes are placed from Longitude/Latitude vertex attributes when present (for example after decorate_graph()), and otherwise with a Kamada-Kawai layout; pass layout = to choose another layout name, a layout function, or a coordinate table. The same layout, node_size, node_labels, node_fill, edges and edge_width options apply to plot() on a gravity field and to animate_popgraphs(). Directed graphs from asymmetric_popgraph() are drawn with arrows. For fully custom figures, use ggraph (see the Visualization article).

lopho |>
  plot()

8.10 Genetic Gravity: Direction from an Undirected Graph

Each edge of a Population Graph is symmetric, but the two populations it joins are compared against different neighbourhoods. Genetic gravity reads the direction of gene flow from that difference: edge asymmetries \(\Delta\), a source–sink score \(S\) for every population, the partitioned distance pGD, tests for a directional gradient, and maps of the gravity field. It has its own chapter, Chapter 9, which walks through the analysis from raw genotypes.

lopho |>
  gravity_field() |>
  plot()

Nodes are placed from `Longitude`/`Latitude` vertex attributes when present (for example after `decorate_graph()`), and otherwise with a Kamada-Kawai layout; pass `layout =` to choose another layout name, a layout function, or a coordinate table. Directed graphs from `asymmetric_popgraph()` are drawn with arrows. For fully custom figures, use ggraph (see the Visualization article).

```{r}
lopho |>
  plot()
```

## Randomization

Generate a random graph with the same nodes and degree sequence as the original (the default, `mode = "degree"`, uses degree-preserving edge swaps), or with the same number of edges placed at random (`mode = "full"`):

```{r}
rg <- lopho |>
  randomize_graph()
rg
```

## Genetic Gravity: Direction from an Undirected Graph

Each edge of a Population Graph is symmetric, but the two populations it joins are compared against different neighbourhoods. *Genetic gravity* reads the direction of gene flow from that difference: edge asymmetries $\Delta$, a source–sink score $S$ for every population, the partitioned distance pGD, tests for a directional gradient, and maps of the gravity field. It has its own chapter, @sec-genetic-gravity, which walks through the analysis from raw genotypes.

```{r}
lopho |>
  gravity_field() |>
  plot()
```
